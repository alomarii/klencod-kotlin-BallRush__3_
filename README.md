# اجمع الكرات (Ball Rush) — لعبة أندرويد
برمجة وتطوير: محمد العمري — 730215825

## التشغيل
1. افتح المجلد في Android Studio (Hedgehog أو أحدث، JDK 17).
2. انتظر مزامنة Gradle ثم Run (أو Build > Build APK).

## طريقة اللعب
- اسحب بإصبعك لتحريك القمع يمينًا ويسارًا، والمس للبدء.
- مرّر الكرات من البوابات: X (ضرب) و + (إضافة)، وتجنب البوابات الحمراء (-) لأنها تمتص الكرات.
- اجمع العدد المطلوب في السلة لتفتح المرحلة التالية. 100 مرحلة، نجوم 1-3.

## الرسومات
- تصادم حقيقي بين الكرات، كرات مجسمة بإضاءة، بوابات وعوارض ثلاثية الأبعاد.
- قائمة رئيسية متحركة، شاشة مراحل بحركة ظهور وتمرير بالقصور الذاتي، نتيجة بنجوم متحركة وقصاصات احتفال.

## الصعوبة (تتزايد مع المرحلة)
بوابات متحركة، مسامير، عوارض مائلة، عوارض دوارة، سلة أضيق وأسرع، بوابات سالبة أكثر وأكبر، وهدف أكبر.
لضبط الصعوبة عدّل الثوابت أعلى ملف GameView.java (GOAL_BASE, GOAL_GROW, MULTS, MAXB).
